تغليف البيانات (Data Encapsulation in OSI Model)

1. Transport Layer (Layer 4)

"Data is segmented, TCP/UDP headers are added."

يتم تقسيم البيانات (Segmented) وإضافة ترويسة TCP/UDP لتكوين Segment.

2. Network Layer (Layer 3)

"IP header is added → forms a packet."

تُضاف ترويسة IP Header (العناوين المنطقية) فتتكون الحزمة Packet.

3. Data Link Layer (Layer 2)

"MAC addresses + Frame header/trailer are added."

تُضاف عناوين MAC وترويسة وذيل الإطار (Header/Trailer) لتكوين Frame.

4. Physical Layer (Layer 1)

"Data is converted into bits and transmitted over the medium."

تتحول البيانات إلى بتات خام (Bits 0/1) وتُنقل عبر الوسط المادي.

مقارنة شاملة: TCP vs. UDP

Reliable & Connection-Oriented

TCP (Transmission Control Protocol)

  • Connection-oriented (requires a connection before data transfer).
    اتصالي التوجه: يتطلب إنشاء اتصال أولاً قبل البدء بنقل البيانات.
  • Reliable (ensures data delivery, retransmits if lost).
    موثوق: يضمن تسليم البيانات، ويعيد إرسال الحزم إذا فُقدت.
  • Error-checking and flow control included.
    يتضمن فحص الأخطاء والتحكم في تدفق البيانات (Flow Control).
  • Slower due to overhead.
    أبطأ نسبياً بسبب العبء الإضافي (Overhead) للترويسات والتأكيدات.
  • Used for applications where accuracy matters (e.g., Web browsing, Email, File transfer).
    يُستخدم في التطبيقات التي تهم فيها الدقة (تصفح الويب، البريد الإلكتروني، نقل الملفات).
Fast & Connectionless

UDP (User Datagram Protocol)

  • Connectionless (no need for setup before sending data).
    غير اتصالي: لا يحتاج إلى إعداد اتصال مسبق قبل إرسال البيانات.
  • Unreliable (no guarantee of delivery, no retransmission).
    غير موثوق: لا يوجد ضمان لوصول البيانات، ولا يعيد إرسال المفقود.
  • Lightweight (less overhead, faster).
    خفيف الوزن: عبء ترويسات أقل (Less overhead) وأسرع في النقل.
  • No flow control.
    لا يحتوي على آلية للتحكم في التدفق (No flow control).
  • Used for real-time applications where speed matters (e.g., Video streaming, Online gaming, VoIP).
    يُستخدم في تطبيقات الوقت الفعلي حيث السرعة هي الأهم (بث الفيديو، الألعاب الأونلاين، مكالمات VoIP).

Slide 7 | Layer 4 (Top) طبقة التطبيقات

1. Application Layer

  • Provides network services to end-users (تقدم خدمات الشبكة للمستخدمين النهائيين)
  • Includes HTTP, FTP, SMTP, DNS (تشمل بروتوكولات HTTP, FTP, SMTP, DNS)
  • Equivalent to OSI Application + Presentation + Session (تعادل طبقات التطبيقات + العرض + الجلسة في نموذج OSI)
Slide 7 | Layer 3 طبقة النقل

2. Transport Layer

  • Ensures reliable delivery (TCP) or fast delivery (UDP) (تضمن التسليم الموثوق عبر TCP أو التسليم السريع عبر UDP)
  • Responsible for segmentation and error control (مسؤولة عن تقسيم البيانات والتحكم في الأخطاء)
  • Example: TCP (web browsing), UDP (video streaming, gaming) (مثال: TCP لتصفح الويب، وUDP لبث الفيديو والألعاب)
Slide 8 | Layer 2 طبقة الإنترنت

3. Internet Layer

  • Handles logical addressing using IP addresses. (تتعامل مع العنونة المنطقية باستخدام عناوين IP)
  • Responsible for routing packets across networks. (مسؤولة عن توجيه الحزم عبر الشبكات)
  • Ensures packet delivery from source to destination. (تضمن إيصال الحزم من المصدر إلى الوجهة)
  • Uses protocols like IP, ICMP. (تستخدم بروتوكولات مثل IP و ICMP، وتعادل طبقة Network في OSI)
Slide 8 | Layer 1 (Bottom) طبقة الوصول للشبكة

4. Network Access Layer

  • Deals with physical addressing (MAC) (تتعامل مع العنونة الفيزيائية MAC)
  • Defines how data is physically sent (Ethernet, Wi-Fi) (تحدد كيف تُرسل البيانات فيزيائياً عبر Ethernet أو Wi-Fi)
  • Equivalent to OSI Data Link + Physical (تعادل طبقتي ربط البيانات Data Link + الفيزيائية Physical في OSI)

الفرق بين Router و Switch

• Router: يعمل في الطبقة 3 (Network)، يستخدم عناوين IP المنطقية لتوجيه الـ Packet.
• Switch / Bridge: يعمل في الطبقة 2 (Data Link)، يستخدم عناوين MAC الفيزيائية لتمرير الـ Frame.
• Hub / NIC / Cable: في الطبقة 1 (Physical) وتنقل Bits.

تطور اسم وحدة البيانات (PDU)

• الطبقات 7 و 6 و 5: Data
• الطبقة 4 (Transport): Segment
• الطبقة 3 (Network): Packet
• الطبقة 2 (Data Link): Frame (تُضاف هنا Header + Trailer)
• الطبقة 1 (Physical): Bits

دمج الطبقات في TCP/IP

• طبقة Application في TCP/IP = تدمج (Application + Presentation + Session) من OSI.
• طبقة Internet في TCP/IP = تقابل طبقة (Network) في OSI.
• طبقة Network Access في TCP/IP = تدمج (Data Link + Physical) من OSI.
